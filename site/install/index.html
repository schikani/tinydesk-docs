    Reading the release...
    The firmware for this board is not on this site right now. Choose another board, or download its image from the releases.

    The installer checks the chip and writes the firmware. Choose Erase device for a first install, and when switching a board between the Desktop and the Shell edition: users, Wi-Fi networks and files then start fresh. (On 4 MB ESP32 boards both editions share one flash layout, so without erasing the files stay.)

    After installing, open the board with Open the web terminal (or PuTTY). The installer’s own Logs & Console is a plain log view: it cannot answer the desktop’s terminal queries or send the mouse, so the desktop shows up there as rows of symbols. Close the installer dialog first, so the port is free.

      Without the browser (esptool)

      The release has this board's firmware as one image, written at offset 0x0: it holds the bootloader (at 0x1000 inside the image on the classic ESP32), the partition table and the app. Install esptool (pip install esptool), download and write it, with your board's port in place of PORT:

      Check the files against SHA256SUMS.txt. Images are not signed; see Security. All options side by side: Install in the documentation.
